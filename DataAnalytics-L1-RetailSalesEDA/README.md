# Retail Sales Exploratory Data Analysis

This project analyses 1,000 retail transactions using Python and pandas.

I examined data quality, product category performance, monthly revenue trends and customer spending patterns.

## Key Findings

- Electronics generated the highest revenue at 156,905.
- Clothing recorded the most transactions (351).
- Beauty had the highest average transaction value (467.48).
- May 2023 recorded the highest monthly revenue (53,150).

## Tools Used

Python, pandas, Matplotlib and Google Colab.
